# 🌿 Herbal Plant Classification

A machine learning project that uses computer vision to identify herbal plants and provide information about their medicinal uses. This system helps in accurate plant identification and promotes knowledge about traditional herbal medicine.

![Machine Learning](https://img.shields.io/badge/Machine%20Learning-Classification-blue)
![Python](https://img.shields.io/badge/Python-3.x-green)
![Deep Learning](https://img.shields.io/badge/Deep%20Learning-CNN-red)

## 🎯 Overview

This project implements multiple machine learning models to classify different species of herbal plants and provides detailed information about their medicinal properties and traditional uses.

## ✨ Features

- 🌱 **Multi-class Plant Classification** - Identifies various herbal plant species
- 💊 **Medicinal Information** - Provides details about medicinal uses
- 🤖 **Multiple ML Models** - Compares different classification approaches
- 📊 **High Accuracy** - Optimized models for reliable predictions
- 📸 **Image-based Detection** - Uses computer vision for identification
- 📚 **Knowledge Base** - Traditional medicine information database

## 🛠️ Technologies & Models Used

### Programming & Frameworks
- **Python** - Core programming language
- **TensorFlow/Keras** - Deep learning framework
- **Scikit-learn** - Machine learning library
- **OpenCV** - Image processing
- **Pandas** - Data manipulation
- **NumPy** - Numerical computing
- **Matplotlib/Seaborn** - Data visualization

### Machine Learning Models
- Convolutional Neural Networks (CNN)
- Transfer Learning (VGG, ResNet, MobileNet)
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)

## 📊 Dataset

The project uses a comprehensive dataset of herbal plant images including:
- Multiple plant species
- Various plant parts (leaves, flowers, roots)
- Different lighting conditions
- Multiple angles and perspectives

## 🚀 Installation & Usage

### Prerequisites
```bash
pip install tensorflow keras opencv-python scikit-learn pandas numpy matplotlib seaborn
```

### Running the Project
```bash
# Clone the repository
git clone https://github.com/PURON98/Herbal-Plant-Classification.git
cd Herbal-Plant-Classification

# Open Jupyter Notebook
jupyter notebook "Herbal Plant Classification.ipynb"
```
